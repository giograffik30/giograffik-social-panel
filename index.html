             Guía Paso a Paso para Conectar las API Reales
          

          
Configuración oficial para publicar desde tu PC a Facebook, Instagram y TikTok de forma automatizada.

        


        

          
          
          

            

              
              
1. Conectar Facebook e Instagram (Meta Graph API)

            

            
    
              
  1. Ingresa al portal developers.facebook.com e inicia sesión con tu cuenta de Facebook.
    2. 
              
  2. Crea una nueva App de tipo "Empresa" (Business) o "Consumidor".
    3. 
              
  3. Añade el producto Instagram Graph API y Páginas de Facebook.
    4. 
              
  4. Ve al Herramientas -> Explorador de Graph API para generar tu token.
    5. 
              
  5. Asegúrate de otorgar los siguientes permisos esenciales:
                
    
                  instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, pages_manage_posts
                
    
              
    6. 
              
  6. Obtén el ID de tu Página de Facebook y el ID de tu Cuenta Profesional de Instagram vinculado.
    7. 
              
  7. Convierte tu token temporal en un Long-Lived Access Token (duración 60 días o permanente).
    8. 
            

          


          
          

            

              
              
2. Conectar TikTok (TikTok Posting API v2)

            

            
    
              
  1. Ingresa a developers.tiktok.com y registra una App.
    2. 
              
  2. Solicita acceso al permiso de API: Content Posting API (Video Kit).
    3. 
              
  3. Configura la URL de redirección OAuth 2.0 (por ejemplo: https://tu-dominio.com/callback).
    4. 
              
  4. Implementa el flujo de autenticación OAuth para requerir los scopes:
                
    
                  user.info.basic, video.upload, video.publish
                
    
              
    5. 
              
  5. Guarda el access_token retornado para adjuntarlo en la cabecera HTTP Authorization: Bearer al enviar la solicitud POST.
    6. 
            

          


        


        
        

          

             Recomendación de Automatización Giograffik
          

          

            Para publicar sin mantener tu computadora encendida a toda hora, puedes conectar las peticiones JSON generadas en la pestaña Payloads API a un servidor backend propio en Node.js/Python o utilizar automatizadores webhooks como Make (Integromat) o n8n.
